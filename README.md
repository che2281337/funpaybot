# FunPay Bot — FunPay в твоём Telegram

Бот для продавцов FunPay в стиле FunPay Cardinal. Им полностью управляешь из Telegram: сообщения покупателей приходят на телефон, отвечать можно прямо оттуда, а лотами, автоответом, автовыдачей и другими функциями управляешь кнопками.

## Возможности

| | |
|---|---|
| 💬 **Сообщения в Telegram** | Новые сообщения сразу приходят в Telegram. Сообщения от поддержки помечаются отдельно |
| ↩️ **Ответ из Telegram** | Ответь **реплаем** на уведомление или нажми «✉️ Ответить». Можно отправить текст или **фото** |
| 📝 **Заготовки** | Готовые ответы, которые отправляются покупателю одной кнопкой |
| 📜 **Чаты и история** | Список последних чатов, история переписки |
| 💰 **Баланс** | Баланс в ₽ / $ / €, а также сколько доступно к выводу |
| 🛒 **Заказы** | Уведомления о новых заказах, список активных заказов, карточка заказа, возврат с подтверждением |
| ⬆️ **Автоподнятие** | Бот сам поднимает лоты во всех категориях, как только FunPay это разрешает |
| 📦 **Управление лотами** | Список лотов (в том числе выключенных). Можно включить или выключить лот, изменить цену, количество, название, описание и любые поля, скопировать или удалить лот |
| ➕ **Создание лота** | Пошаговый мастер: раздел → название → описание → цена → кол-во → параметры кнопками |
| 🤖 **Автоответ** | Команды (`!помощь`, `привет\|здравствуйте` …) с готовыми ответами |
| 👋 **Приветствие** | Автоматическое сообщение новым покупателям. Повторяется, если покупатель не писал N дней |
| ⭐ **Ответы на отзывы** | Бот автоматически отвечает на отзыв. Для каждой оценки (1–5⭐) свой текст |
| ✅ **Ответ на подтверждение** | Благодарность покупателю после подтверждения заказа |
| 🚚 **Автовыдача** | Товары из файла (одна строка = 1 шт.) выдаются сразу после оплаты, по количеству в заказе |
| ♻️ **Автовосстановление** | Если лот выключился после продажи, бот включит его снова. Когда товары кончились, бот может выключить лот |
| 🟢 **Вечный онлайн** | Аккаунт всё время в сети |
| ⛔ **Чёрный список** | Этим покупателям бот не выдаёт товар и не отвечает автоматически |
| 🔔 **Гибкие уведомления** | Каждый тип уведомлений включается и выключается отдельно |
| 🔐 **Админка** | Вход в панель по паролю. Можно добавить несколько админов. Пароль и golden_key меняются из Telegram, там же логи и перезапуск |

Переменные в текстах: `$username`, `$chat_name`, `$order_id`, `$order_title`, `$order_link`, `$product`, `$date`, `$time`, `$message_text`.

## Установка

Нужен **Python 3.10+** ([python.org](https://www.python.org/downloads/); на Windows при установке поставь галочку «Add to PATH»).

1. Скачай проект (Code → Download ZIP) и распакуй его.
2. Запусти бота:
   - **Windows**: двойной клик по `start.bat`
   - **Linux / macOS**: `./start.sh`

   При первом запуске скрипт сам установит зависимости.
3. Бот спросит:
   - **golden_key** — cookie FunPay. Как его найти: зайди на funpay.com → `F12` → вкладка *Application* (*Хранилище*) → *Cookies* → `https://funpay.com` → скопируй значение `golden_key`.
   - **User-Agent** браузера, в котором ты вошёл на FunPay. Узнать его можно на сайте [whatsmyua.info](https://www.whatsmyua.info/). Можно нажать Enter и оставить значение по умолчанию.
   - **Токен Telegram-бота** — создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
   - **Пароль** для входа в панель.
   - **Прокси** (необязательно).
4. Открой своего бота в Telegram, нажми `/start` и отправь пароль. Готово 🎉

Настройки хранятся в папке `storage/`. Их можно править и вручную, но удобнее из Telegram.

### Запуск на сервере (VPS) через Docker

```bash
export FUNPAY_GOLDEN_KEY=... TELEGRAM_TOKEN=... TELEGRAM_PASSWORD=...
docker compose up -d --build
```

Без Docker бота можно держать запущенным через `screen`/`tmux` (`./start.sh`) или systemd.

## Как пользоваться

- **Ответить покупателю** — ответь реплаем на уведомление: текст или фото (с подписью) уйдёт в чат FunPay. Ещё можно нажать «✉️ Ответить» или «📝 Заготовки».
- Кнопки внизу экрана: **💬 Чаты · 🛒 Заказы · 📦 Лоты · 💰 Баланс · ⚙️ Панель управления · 📊 Статус**.
- Команды: `/menu`, `/chats`, `/orders`, `/lots`, `/balance`, `/raise`, `/status`, `/cancel`, `/logout`.
- **Автовыдача**: Панель → 🚚 Автовыдача → ➕ Добавить лот. Укажи часть названия лота и текст с `$product`, затем загрузи товары текстом или .txt-файлом. Ещё проще открыть лот в «📦 Лоты» и нажать «🚚 Автовыдача».
- **Новый лот**: «📦 Лоты» → «➕ Новый лот» → вставь ссылку на раздел (`https://funpay.com/lots/1142/`) и следуй шагам. Ещё быстрее открыть похожий лот и нажать «📋 Копировать».
- **Выключенные лоты** FunPay не показывает в профиле. Нажми «🔄 Обновить (+ выключенные)» — бот найдёт их в твоих разделах.

## Структура

```
main.py              — запуск и мастер первичной настройки
cardinal/            — ядро: события FunPay, автоответ, автовыдача, отзывы, автоподнятие, лоты
tg_bot/              — Telegram-панель (меню, уведомления, лоты, настройки)
FunPayAPI/           — библиотека для работы с FunPay (форк FunPayAPI by Woopertail, GPL-3.0)
storage/             — настройки, автоответы, товары автовыдачи (создаётся при запуске)
tests/               — тесты (python -m unittest discover tests)
```

## Важно

- **Никому не передавай** `golden_key` и файлы из `storage/`: с ними можно получить полный доступ к аккаунту FunPay.
- Бот работает через веб-интерфейс FunPay. Если FunPay изменит вёрстку сайта, какие-то функции могут перестать работать до обновления парсера (`FunPayAPI/`). Логи лежат в `logs/log.txt`, их можно получить в Telegram: Настройки → 📄 Логи.
- Используй бота в рамках правил FunPay.
